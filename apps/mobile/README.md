# BluelineGPT Mobile

Flutter is the approved mobile technology for Android and iOS. The local Flutter SDK is not installed, and Prompt 1 does not implement mobile business workflows.

A future approved mobile phase will create the Flutter application with:

- Driver and Trader role boundaries.
- Shared versioned API contracts.
- Secure token storage.
- Arabic/English localization and RTL/LTR behavior.
- Testable adapters for maps, calling, GPS, camera, and photos.

Business calculations, permissions, and tenant enforcement remain in the backend API.
