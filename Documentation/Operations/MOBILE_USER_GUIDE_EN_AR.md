# BluelineGPT Mobile Operational Guide — English / العربية

## Trader / التاجر

Sign in with the account supplied by your Company. Create Orders only from verified Customer details; review the mobile number, Area, address, and COD before submission. Pricing comes from the server. Track only your Orders, open settlements/statements when available, cancel only when the current status permits, and message the Office—not a Driver or Customer directly. If data is marked unavailable or stale, refresh when connected.

سجّل الدخول بحساب الشركة. أنشئ الطلب بعد مراجعة بيانات العميل ورقم الهاتف والمنطقة والعنوان ومبلغ الدفع عند الاستلام. التسعير من الخادم. تابع طلباتك فقط، واعرض التسويات والكشوف عند توفرها، وألغِ الطلب فقط عندما تسمح حالته، وتواصل مع المكتب فقط. حدّث البيانات عند ظهور أنها غير متاحة أو قديمة.

## Driver / السائق

Open Assigned Orders, verify the Order, then use only the offered action: Start Delivery, Delivered, or report failure. For delivery, choose Cash or Bank, enter actual COD safely, and add the Bank reference when required. Pending Sync is not confirmation. Keep the action visible, reconnect, and use Sync Issues; never repeat it with a new logical action. Conflicts need Office review. Drivers cannot cancel, reconcile, or mark Returned to Trader. Message the Office only.

افتح الطلبات المسندة وتحقق من الطلب، ثم استخدم الإجراء المتاح فقط: بدء التوصيل أو تم التوصيل أو الإبلاغ عن فشل. اختر نقداً أو بنكاً، وأدخل المبلغ الفعلي ومرجع البنك عند الحاجة. «بانتظار المزامنة» ليست تأكيداً. أعد الاتصال وافتح مشاكل المزامنة. التعارض يحتاج مراجعة المكتب. لا يمكن للسائق الإلغاء أو التسوية أو تحديد «مرتجع إلى التاجر». تواصل مع المكتب فقط.

## Operator / المشغّل

Use only actions granted by current permissions: assignment/reassignment, failure review, return instruction, and branch receipt where authorized. Mobile is not the full finance/reconciliation workspace. Refresh after permission changes and review synchronization conflicts before any server-side resolution. Use the Office Communication Center only for authorized Company conversations.

استخدم الإجراءات التي تسمح بها الصلاحيات الحالية فقط: الإسناد أو إعادة الإسناد، ومراجعة الفشل، وتعليمات الإرجاع، وتأكيد استلام الفرع عند التفويض. تطبيق الهاتف ليس بديلاً كاملاً للمالية أو التسوية. حدّث الصلاحيات وراجع تعارضات المزامنة قبل الحل. استخدم مركز اتصالات المكتب للمحادثات المصرح بها فقط.

## Customer / العميل

Use only your authenticated account or secure tracking link. View Customer-safe status and notifications, report an issue, and message the Office. Delivery fees, settlement information, internal notes, and private Driver information are not shown. Customers cannot change Order status or contact the Driver directly.

استخدم حسابك الموثق أو رابط التتبع الآمن فقط. اعرض الحالة والإشعارات المخصصة للعميل، وأبلغ عن المشكلة، وتواصل مع المكتب. لا تظهر رسوم التوصيل أو بيانات التسوية أو الملاحظات الداخلية أو بيانات السائق الخاصة. لا يمكن للعميل تغيير حالة الطلب أو التواصل المباشر مع السائق.

## Security and support / الأمان والدعم

Do not share passwords, verification links, or notification contents. Log out before another person uses the device. A notification is not proof that an Order action succeeded; open the app and refresh authoritative data. If the account, Company, or permissions look wrong, stop and contact the approved support channel. The support contact is a release dependency and is not yet recorded.

لا تشارك كلمة المرور أو روابط التحقق أو محتوى الإشعارات. سجّل الخروج قبل أن يستخدم شخص آخر الجهاز. الإشعار ليس دليلاً على نجاح إجراء الطلب؛ افتح التطبيق وحدّث البيانات. إذا كان الحساب أو الشركة أو الصلاحيات غير صحيحة فتوقف واتصل بقناة الدعم المعتمدة، وهي لم تُسجل بعد.
