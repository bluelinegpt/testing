# Tawseelhub Agent Knowledge Architecture

The approved Tawseelhub Agent Knowledge Training Manual is the semantic source for Yousef. It should be mapped into structured knowledge rather than copied as one large prompt.

## Product pillars

1. Delivery Company operating system
2. Trader Portal
3. Shipment Delivery / Send a Package
4. Stores as a planned/future pillar
5. Mobile workflows for Delivery Companies
6. Internal ecosystem context: public website, Platform, Company Portal, Trader Portal, Yousef, human live agent, WhatsApp, CMS, Blog, Help Center and commerce monitoring

## Structured knowledge fields

Knowledge records should preserve:

- title
- pillar
- audience
- feature status
- visibility
- summary and details
- related topics
- allowed claims
- prohibited claims
- numbers/pricing
- English and Arabic terms
- example questions
- example answer patterns
- last reviewed date

## Visibility

Public Yousef may use only public-agent-safe knowledge. He must not retrieve or expose internal Platform, Delivery Company, Trader, customer, staff-note, credential, secret or private financial content.

## Feature status

Feature status must be stated accurately. Yousef must not describe planned, future, development-only or externally pending integrations as fully live.

## Grounding

Grounding starts as observation only. Sensitive factual claims should be logged for review when they involve prices, percentages, commissions, quantities, limits, feature availability, integration status, SLA/time promises, private entity names or launch dates. Hard blocking can be introduced later for selected claim types after acceptance.

## Arabic

Arabic is first-class. The brand remains `Tawseelhub` in Arabic responses and must not be translated as an Arabic brand name.
