# Translation Key Standards

- Organize keys by feature and semantic purpose, for example `workspace.title`.
- Keep English and Arabic catalogs structurally aligned.
- Use keys for user-facing labels, messages, validation summaries, and commands.
- Do not use an English sentence as the key.
- Do not build sentences by concatenating translated fragments.
- Keep business identifiers, stable API error codes, and permission codes language-neutral.
- Prefer interpolation for safe variable values and pluralization rules for counts.
- Review Arabic meaning and context rather than relying on literal word substitution.
